# Pinyon Shift 0.8.3-preview.1

This is a beta build.

Each launcher still builds the game on your machine from your own disc; none
of the downloads contains the game. Older launchers offer this update from
**Update to 0.8.3-preview.1**; the game is built again after the update, and
saves, settings and DLC stay where they are.

## Changed

- **Online play is off on the Quest build**: the Quest build no longer
  connects to the live service, so quick match and the other online modes
  are unavailable until the next build turns them back on.

## Fixed

- **Antialiasing stays off** for graphics configurations that did not ask
  for it: the launcher no longer defaults to MSAA on.

## Known limitations

The limitations listed for [0.8.2](https://github.com/arcanite24/pinyon-shift/blob/main/docs/releases/0.8.2.md#known-limitations) still apply.
The Intel Mac launcher remains experimental.
